# Renode for Zed

Language support for Renode platform descriptions (`.repl`) and monitor scripts (`.resc`).

- Syntax highlighting, brackets, indentation queries and outlines for both languages.
- Monitor highlighting inside platform `init`, `reset` and `preinit` bodies.
- Embedded Python highlighting in monitor `python` blocks and platform `script` properties.

Embedded Python highlighting requires Zed's Python language support.

For installation from a checkout, follow the [development extension guide](../../docs/zed.md).
